# Credit-Risk-Scorecard
Builds a classic FICO-style credit scorecard from a 32,581-row credit risk dataset (applicant demographics + loan terms, binary default outcome). The pipeline cleans the data (duplicate removal, outlier handling), bins each predictor and converts bins to Weight-of-Evidence (WOE), fits a logistic regression on the WOE-transformed features, and rescales the coefficients into integer points via PDO (points-to-double-odds) log-odds scaling — the standard construction used in consumer credit underwriting. The model reaches 0.874 AUC / 0.747 Gini / 0.616 KS, and the resulting score separates risk monotonically across bands (69% observed default rate in the lowest band vs. 0% in the highest). Variables are screened by Information Value before fitting. Includes an interactive HTML/SVG report (ROC curve, score distribution, variable-importance ranking, per-bin WOE chart, worked scoring example) and a matplotlib script for local chart rendering. Built with Python, pandas, scikit-learn.
